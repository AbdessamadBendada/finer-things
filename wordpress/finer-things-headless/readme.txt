Structured ACF Free-compatible project fields for the Finer Things headless WordPress CMS.

== Installation ==

1. Install and activate Advanced Custom Fields Free.
2. Upload finer-things-headless.zip in Plugins > Add New > Upload Plugin.
3. Activate Finer Things Headless.
4. Open Projects > Add New and expand Meta Boxes.

== Version 0.1.0 ==

Adds fixed fields for four editorial project chapters, four gallery images,
project ordering, and an optional listing image. All fields are exposed through
the WordPress REST API. The existing manually created Location, Introduction,
and Hero Image fields remain authoritative and are not duplicated.
